# Strum

A follow-along guitar chord player. The big box shows the chord to play now and lights up each strum in time. The small box shows the chord coming next.

**Play it:** [drewnotweird.co.uk/strum](https://www.drewnotweird.co.uk/strum)

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Runs on http://localhost:5191.

## Adding a song

Add a JSON file to `frontend/src/songs/`. See `PLAN.md` for the format and the copyright rules.
